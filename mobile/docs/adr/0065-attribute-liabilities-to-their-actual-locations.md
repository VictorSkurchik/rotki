# Attribute liabilities to their actual locations

Every Portfolio Source and Manual Entry will own one canonical Allocation Location inherited by all of its Balance Contributions. Blockchain-account Sources use `blockchain`, exchange Sources use their canonical exchange-provider location, and Manual Entries use the location selected in the Full Client. Shared code derives each location's `known_assets_value`, `known_liabilities_value`, and `known_net_value`, subtracting a liability only from its own location and requiring the overall known totals to equal the exact sums across locations. The Companion intentionally does not preserve the legacy aggregate behavior that subtracts every liability from the blockchain bucket regardless of origin. Location net values may be negative, partial Valuation Coverage remains explicit, and percentages are presentation-only. A Source's location is part of its required common envelope so Unsupported Sources remain allocatable without understanding their variant-specific fields.
