# Publish dense History Event ordinals

`HistoryEvent.sequence` will be a required zero-based dense ordinal assigned only after exact joining, Curated History inclusion, and canonical presentation ordering. A Group with N Events contains each integer from `0` through `N-1` exactly once, and its `events` array is ordered by that field. The Engine's mutable raw `sequence_index` remains an internal ordering input and is never copied to the Companion wire contract: it may contain gaps, has no persisted non-negative range guarantee, and can collide when separate raw groups are joined. A change to raw indices that leaves projected order and content unchanged is invisible; a real public reorder recomputes ordinals and advances History Generation and Revision without retiring IDs when lineage remains proven. Filtering returns the complete stored order and never renumbers a response. This gives Kotlin and Swift one bounded integer invariant without exposing database mechanics or relying on Summary roles to order auxiliary and generic Events.
