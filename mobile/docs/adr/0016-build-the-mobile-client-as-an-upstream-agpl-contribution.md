# Build the mobile client as an upstream AGPL contribution

The KMP mobile Client will be developed as an AGPL-licensed contribution intended for the official Rotki project rather than as a separately branded or proprietary fork. Repository conventions and the contributor agreement will be respected, while application names, bundle and package identifiers, store listings, and use of Rotki trademarks or artwork remain undecided until the maintainers approve the direction.
