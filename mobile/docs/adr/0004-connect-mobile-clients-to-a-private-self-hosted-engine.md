# Connect mobile clients to a private self-hosted engine

The first mobile release will connect to an always-on Engine Host operated by the user, such as a home server, NAS, or private VPS. The Engine will be reachable over HTTPS only through the user's local network or private VPN; direct public-Internet exposure and a Rotki-operated hosted Engine are outside the first-release scope, preserving the product's self-hosted privacy model while avoiding an engine port to mobile.
