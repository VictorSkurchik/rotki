# Value each snapshot in the profile main currency

Every Portfolio Snapshot will carry one required `valuation_currency` equal to the Profile's current `main_currency` at its coherent capture boundary. The field uses the canonical Engine asset identifier, and every non-null Balance Contribution value, known asset value, known liability value, known net value, and later monetary aggregate in that Snapshot is expressed in it. Individual rows do not repeat a currency and the protocol does not duplicate USD valuations. A Full Client change to main currency changes canonical Snapshot content and produces a new Snapshot Revision even when underlying amounts are unchanged; an encrypted older Snapshot keeps its original currency and is never relabelled or converted by the Client. Any Engine resource backed internally by legacy USD history must convert at the Snapshot boundary or omit an unavailable valuation rather than mix currencies. This makes monetary comparison and aggregation unambiguous while respecting the owner's existing Profile preference.
