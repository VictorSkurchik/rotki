# Collapse internal balance labels at the contribution boundary

Portfolio Snapshot version 1 will contain exactly one Balance Contribution for each `(origin, category, asset_id)` tuple, with no independent contribution identifier. The Engine exactly sums blockchain protocol labels, default address labels, adapter buckets, and other internal leaves before serialization; if any constituent valuation is unavailable, the collapsed value is null rather than an understated partial sum. Duplicate tuples are contract failures rather than Client-side merge instructions. Different origins and Asset versus Liability categories remain separate even for the same asset. Internal protocol labels are not stable cross-Source identities, and exchanges do not provide equivalent granularity, so exposing them would create an uneven and implementation-coupled Portfolio model; label-only churn does not change Snapshot Revision. Protocol, lending-position, staking, or DeFi detail may be introduced later only through a separate typed and versioned Capability, without changing the identity or cardinality of the version-1 contribution.
