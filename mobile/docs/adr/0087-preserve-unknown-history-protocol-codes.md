# Preserve unknown History protocol codes

`HistoryEvent.entry_kind`, `event_type`, and `event_subtype` will be required open protocol-code strings rather than closed wire enums. Each code is 1–64 ASCII bytes matching `^[a-z][a-z0-9]*(?:_[a-z0-9]+)*$`; subtype `none` is a real value, never null. An explicit checked-in Companion vocabulary maps current Engine concepts to stable lower-snake-case codes that are never derived at runtime from Python enum names or the general API's space-separated serialization, renamed, or reused. Shared KMP models each domain independently as `Known` or `Unknown(rawCode)` with a project-owned bare-string serializer. A syntactically valid unknown code preserves the complete Event, exact raw value, Revision, and generic presentation; it does not authorize inferred behavior, but an independently valid known Summary or Detail remains usable. Malformed required codes reject a candidate or page atomically rather than dropping a leg. Event-type and subtype filters compare exact codes and may echo an observed unknown code, while `entry_kind` remains response-only in version 1. This permits Engine vocabulary growth without sacrificing group completeness or exact offline round-tripping.
