# Preserve complete groups in Curated History

Curated History will exclude Engine-derived hidden display duplicates, preserve customized and accounting-ignored activities as ordinary History, and apply ignored-asset visibility only at the complete display-group boundary. A group whose every otherwise visible leg uses an ignored asset is omitted; a mixed group is returned with every meaningful leg, including ignored-asset legs, so swaps, movements, bridges, and fees never become financially incomplete. These rules run after the Engine's underlying-group History Entitlement window is fixed, so hidden or ignored-only groups do not refill quota from older records. Internal hidden, customized, ignored-accounting, and ignored-asset markers remain off the wire, while any state change that alters curated membership or content advances History Generation and republishes the Snapshot. This deliberately differs from row-level ignored-asset filtering in the general History API to protect the semantic integrity of the mobile read model.
