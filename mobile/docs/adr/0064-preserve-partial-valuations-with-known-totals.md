# Preserve partial valuations with known totals

An unavailable price in the Portfolio Snapshot will be represented by a null Balance Contribution `value`, while a genuine exact zero remains the decimal string `"0"`. Overview exposes `known_assets_value`, `known_liabilities_value`, and `known_net_value`, calculated only from non-null valuations in the Snapshot's one Valuation Currency. Shared code derives Complete or Partial Valuation Coverage exhaustively from the contribution collection and native Clients label partial totals as known value rather than full net worth; no duplicate coverage flag is serialized. Missing valuation never removes the fungible amount or becomes an invented zero. Valuation Coverage remains independent from Source Health and Snapshot Coverage, so successful external refresh and successful price discovery are not falsely conflated. Changes between null and a concrete valuation are canonical Snapshot content and produce a new Snapshot Revision.
