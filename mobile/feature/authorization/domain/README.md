# Authorization domain

This Ktor-free KMP leaf owns the redacted challenge, proof, and Access Session contracts used by
the authorization application policy. It exposes a narrow remote gateway and transcript-encoder
port while keeping DTOs, HTTP clients, credentials in diagnostics, native security implementations,
and Pairing behavior outside the module.

The module creates no Apple framework. Its Kotlin integration contracts are hidden from Objective-C
and Swift and are consumed only through composition roots.
